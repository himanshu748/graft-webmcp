# Product

## Platform

web

## Stack

Inferred from the build request: React, TypeScript and Vite. This keeps the judged experience fast to deploy and lets the product register WebMCP tools from one trusted top-level document.

## Users

Primary: site owners, frontend engineers and technical consultants evaluating how an existing interface could become agent-operable.

Secondary: WebMCP Challenge judges who need to verify the product's mechanism and value in under one minute.

## Product Purpose

Graft compiles an owned or explicitly permitted inert page snapshot, identifies useful semantic structures and previews a typed WebMCP layer without requiring changes to the original source. Success means a first-time user can compile a permitted page, inspect the generated contracts and complete a task through a visible WebMCP call in less than 60 seconds.

## Positioning

Graft is a governed tool layer for websites that never shipped one. It turns page semantics into reviewable WebMCP contracts at runtime, then exports the reviewed adapter a site owner can harden and ship.

## Operating Context

- The judged path runs in the latest ChatGPT desktop in-app browser with Site tools or Chrome 149+ with WebMCP testing enabled.
- Three original fixture pages provide a deterministic raw-page versus compiled-page comparison.
- The inspector, preview and call timeline remain visible while tools are registered and invoked.
- The official challenge deadline is September 3, 2026 at 1:00 pm PDT.

## Capabilities and Constraints

- Compile headings, repeated collections, tables and search controls into deterministic tool candidates.
- Register approved tools through `document.modelContext.registerTool()`.
- Mark imported outputs as untrusted and read-only unless a controlled fixture explicitly demonstrates a consequential local action.
- Explain every confidence score and hold ambiguous candidates for review.
- Test tools, view exact arguments and results, edit candidate metadata and export a reviewed adapter.
- Persist edits locally for the hackathon build. There is no anonymous shared registry.
- Do not execute imported scripts, forward credentials or cookies, mutate third-party state or claim arbitrary-site compatibility.
- URL intake is future work. The release accepts only the three owned fixtures and never fetches arbitrary sites.

## Brand Commitments

- Voice: concise, technically exact and evidence-led.
- Core line: "A governed tool layer for websites that never shipped one."
- Avoid universal compatibility claims, security-control circumvention language and invented adoption metrics.

## Product Principles

1. Prove the tool call, not just the interface.
2. Fail closed when the page or target is ambiguous.
3. Keep source content untrusted and consequential actions human-controlled.
4. Prefer three deterministic demos over broad unsupported claims.
5. Treat export as the path from preview to owner-shipped adoption.

## Accessibility & Inclusion

The experience must work from 360px to 1440px, support keyboard-only use, preserve visible focus, meet WCAG AA contrast and respect reduced-motion preferences.
