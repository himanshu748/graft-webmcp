## Typography: IBM Plex Sans + IBM Plex Mono

- **Display and body:** IBM Plex Sans
- **Mono for code, counters and schemas:** IBM Plex Mono

The Vite entry imports self-hosted `@fontsource` packages in `src/main.tsx`. CSS variables `--font-sans` and `--font-mono` are available globally.

### Type scale

| Role | Size | Use |
|---|---|---|
| Display | `clamp(3rem, 7vw, 6.5rem)` | Hero only |
| Page title | `clamp(2rem, 4vw, 3.5rem)` | Major page heading |
| Section | `clamp(1.75rem, 3vw, 2.75rem)` | Section breaks |
| Subsection | `1rem` | Card and panel titles |
| Body | `0.9375rem` | Default UI text |
| Reading | `1rem / 1.65` | Explanatory copy |
| Caption | `0.75rem` | Meta and timestamps |
| Mono | `0.75rem` | Tool names, counters, schemas and calls |

## Gradients

Exactly two brand gradients are available. Use no more than one per screen region.

### Background gradient

```css
/* Light */
--gradient-bg: linear-gradient(135deg, oklch(0.985 0.006 20) 0%, oklch(0.955 0.011 35) 100%);

/* Dark */
--gradient-bg: linear-gradient(135deg, oklch(0.115 0.012 20) 0%, oklch(0.145 0.017 35) 100%);
```

Use for the hero or another large empty area. Do not place small body text directly over the changing midpoint.

### Accent gradient

```css
/* Light */
--gradient-accent: linear-gradient(to right, oklch(0.48 0.19 25) 0%, oklch(0.50 0.18 55) 100%);

/* Dark */
--gradient-accent: linear-gradient(to right, oklch(0.70 0.19 25) 0%, oklch(0.73 0.18 55) 100%);
```

Use for a focal edge, compact badge or decorative media treatment. Keep text on a solid surface.

## Tone and voice

### Words to use

Be direct, specific and number-forward. Prefer verbs over adjectives. Name the concrete operation: compile, sanitize, derive, review, register, run and export.

### Words to avoid

Avoid hype such as revolutionary, game-changing, unleash, supercharge, seamless and powerful. Do not call the product universal. Do not hide uncertainty behind marketing language.

### Voice example

> 3 tools derived. 2 registered. 1 held for review.

## Usage dos and don'ts

**Do:**

- Use semantic CSS variables instead of hardcoded component colors.
- Keep spacing on a 4 px grid.
- Use IBM Plex Mono with tabular numerals for changing values.
- Reserve signal red for the primary action, active selection and branded focal moments.
- Test every interactive state in both light and dark contexts.
- Respect `prefers-reduced-motion` with an instant path.

**Don't:**

- Add a second decorative accent color.
- Stack both gradients in the same region.
- Use the accent gradient behind body copy.
- Use `transition: all`.
- Turn every label into uppercase microcopy.
- Replace product evidence with decorative imagery.
